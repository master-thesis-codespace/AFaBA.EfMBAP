# Master's Thesis AFaBA.EfMBAP: Supplementary Materials

This repository is the space storing supplementary materials like the source code for references. The acronym stands for the the thesis' title. Although the code is NOT intended to be publicly available, the repository is public to easily reference code snippets via permalinks in the internal document. Copyright applies.

## Code explanations 
There are several comments added in the code (mostly in-line) to support understanding row-by-row. For further information on how specific code snippets were used and executed, please have a look into the internal master's thesis.

For some python-scripts, a bash file (e.g. job-script.sh) is stored within the same directory. It will inform about the way execution was invoked.

## Expiration
This public repository will be deleted some weeks or months after the master's thesis was presented. Permalinks will not work from there on.
